\subsection*{Mã nguồn}

Notebook triển khai đầy đủ các bài tập:

\begin{center}
\texttt{LAB04/Lab04-Ex.ipynb}
\end{center}

Hướng dẫn chạy:

\begin{verbatim}
# 1. Khởi động Docker Kafka
docker compose up -d

# 2. Kích hoạt môi trường ảo
source venv/bin/activate

# 3. Mở JupyterLab
jupyter lab

# 4. Mở và chạy toàn bộ: LAB04/Lab04-Ex.ipynb (Run All Cells)
\end{verbatim}
